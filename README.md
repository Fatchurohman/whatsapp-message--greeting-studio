# WhatsApp Message & Greeting Studio (Proyek Ke-31)

Aplikasi web praktis untuk menghasilkan berbagai macam ucapan di grup WhatsApp (belasungkawa dengan teks Arab/doa, hari ulang tahun, hari raya dalam bahasa Indonesia maupun bahasa Jawa), lengkap dengan **Generator Huruf Unik (Unicode)** untuk mem-bypass keterbatasan format teks bawaan WhatsApp.

## Fitur Utama
1. **Multi-Kategori & Multi-Bahasa**: Menyediakan templat pesan formal, santai, hingga ragam bahasa Jawa halus (Krama) berbalut doa/teks Arab yang rapi.
2. **Unicode Text Transformer**: Mengubah teks biasa menjadi gaya huruf tebal (*bold* sans), miring (*italic*), kaligrafi (*script*), atau kotak (*monospace*) secara instan.
3. **One-Click Copy**: Tombol salin otomatis untuk memudahkan langsung dipaste ke chat WhatsApp.

## Teknologi yang Digunakan
- HTML5 & CSS3 (Modern Flexbox & Grid Layout)
- Vanilla JavaScript ES6+ (Aman, ringan, tanpa *external dependencies*)
